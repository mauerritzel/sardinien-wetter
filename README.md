# Sardinien Wetter

Ruft alle 3 Stunden Wetter- und Seegangsdaten von Open-Meteo für 22 Orte der Sardinien-Reise (4.–17.10.2026) ab und speichert sie unter `data/`.

- `data/latest.md` – kompakte Tabellen je Ort (10 Tage)
- `data/latest.json` – alle Werte

Manuell starten: Actions → „Wetter abrufen“ → „Run workflow“. Nach der Reise kann das Repo gelöscht oder der Workflow deaktiviert werden.
